# Hangman

A command-line Hangman game written in Python.

## How to play

1. Make sure you have Python 3 installed.
2. Download or clone this repository.
3. In a terminal, go into the project folder and run:

   ```
   python3 main.py
   ```

4. Guess one letter at a time. Each wrong guess adds a piece to the gallows.
   Guess the whole word before the hangman is complete to win.

## Files

- `main.py`: the game
- `wordlist.txt`: the words the game picks from (one word per line)

## Adding your own words

Open `wordlist.txt` and add new words, one per line.
